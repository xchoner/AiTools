Hosting & Form Setup Guide

1. Deploying for Free on GitHub Pages ($0 / month)

  1. Create a new public repository on GitHub (e.g., ai-tools-directory).
  2. Upload all files from this project: index.html, style.css, script.js, tools.json, and README.md.
  3. In your GitHub repository, go to Settings > Pages.
  4. Under Build and deployment, set Source to Deploy from a branch.
  5. Select the main branch and / (root) folder, then click Save.
  6. Your site will be live at https://<username>.github.io/<repo-name>/ in 1–2 minutes!

2. Connecting Formspree or Web3Forms for Free Email Submissions

Because GitHub Pages is a static host with no backend database, submissions cannot write to tools.json directly. Instead, Formspree or Web3Forms delivers submissions straight to your inbox:

  • Option A: Formspree (Free plan: 50 submissions/mo)
    1. Register for free at formspree.io.
    2. Click + New Form, name it "AI Directory Submissions", and enter your notification email.
    3. Verify your email address. Copy your form endpoint URL (e.g., https://formspree.io/f/mlekoqwe).
    4. In script.js, set SUBMISSION_CONFIG.provider = 'formspree' and paste your endpoint into formspreeEndpoint.
  • Option B: Web3Forms (Free plan: 250 submissions/mo)
    1. Visit web3forms.com and enter your email address.
    2. Copy the Access Key sent to your email inbox.
    3. In script.js, set SUBMISSION_CONFIG.provider = 'web3forms' and paste your key into web3FormsAccessKey.
